# Security Policy

## Security Support

Clementine is maintained on the current development branch of this repository.

Security fixes are applied to the current development version as appropriate. Older releases and versions are not maintained as separate supported branches.

Users should keep Clementine up to date to receive security fixes and other maintenance updates.

## Reporting a Vulnerability

If you discover a potential security vulnerability in Clementine, please report it privately rather than opening a public issue.

Use GitHub's private vulnerability reporting feature for this repository, when available. Please provide enough information to investigate the report, including:

* A description of the vulnerability.
* The affected component or functionality.
* Steps to reproduce the issue.
* Relevant logs, crash information, or other diagnostic details.
* A proof of concept, if one is necessary to demonstrate the vulnerability.

Please do not publicly disclose the vulnerability or post sensitive reproduction details until it has been investigated.

The maintainer will review submitted reports and provide an acknowledgement or follow-up when practical. Reports that are determined not to represent security vulnerabilities may be handled through the project's normal issue tracker.

## Security Updates

Confirmed security vulnerabilities will be addressed according to their severity and practical impact. Once a fix is available, the relevant changes may be included in the project's normal development history and release process.

Users are encouraged to update to the latest available version of Clementine to obtain security fixes and other maintenance updates.
